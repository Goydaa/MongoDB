# КТ-01 — инвентаризация склада

**Автор:** Даниил Бодров  
**Группа:** РПО2

## Файлы проекта

- `inventory.py` — загружает данные фактического пересчёта, сверяет их с учётными остатками, исправляет расхождения, отмечает пустые полки и записывает результаты в журнал.
- `stocktake.json` — данные пересчёта из задания преподавателя.
- `check.py` — скрипт проверки корректности выполнения задания.
- `report_template.md` — шаблон отчёта.
- `inventory.md` — итоговый отчёт с результатами инвентаризации.

## Запуск

Все команды необходимо выполнять из корня репозитория `mongodb-practice`.

### 1. Сброс тестового окружения

```powershell
docker compose run --rm reset
```

### 2. Первый запуск инвентаризации

```powershell
docker compose run --rm python work/kt01/inventory.py
```

### 3. Проверка результата

```powershell
docker compose run --rm python work/kt01/check.py
```

### 4. Повторный запуск инвентаризации

```powershell
docker compose run --rm python work/kt01/inventory.py
```

### 5. Повторная проверка

```powershell
docker compose run --rm python work/kt01/check.py
```

Проверка должна успешно завершиться после обоих запусков.

Повторный запуск позволяет проверить идемпотентность скрипта: повторное выполнение не должно создавать дубликаты документов пересчёта или повторные записи журнала за ту же дату.

## Результаты

Фактические результаты инвентаризации, выявленные расхождения, изменённые документы и сведения о пустых полках приведены в файле `inventory.md`.
